AI & Data Science Portfolio Starter

1. Extract this ZIP.
2. Open the AI_DS_Portfolio folder in Visual Studio Code.
3. Open index.html in Chrome to preview.
4. Edit index.html for your details; style.css controls appearance; script.js adds the mobile menu.
5. Before publishing, verify email and LinkedIn, replace the GitHub placeholder with your profile, add your resume PDF and project links.
6. Keep only skills, results and project features you have actually implemented and can explain in an interview.
The project art is made with CSS and is illustrative, not a photo of your hardware.
